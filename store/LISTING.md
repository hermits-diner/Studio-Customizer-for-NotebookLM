## 한국어 (ko)

**짧은 설명:**
NotebookLM 오디오 오버뷰·슬라이드·퀴즈를 내 목적에 맞게 — 맞춤설정 프롬프트를 만들어 클릭 한 번으로 삽입하세요.

**자세한 설명:**

NotebookLM의 맞춤설정 입력란, 열어놓고 뭐라고 써야 할지 막막했던 적 있나요?

Studio Customizer는 산출물 유형을 고르고 대상·목적만 입력하면 전문가 수준의 맞춤설정 프롬프트를 실시간으로 만들어 주고, 클릭 한 번으로 NotebookLM에 삽입합니다.

✦ 주요 기능
• 9종 산출물 지원 — 오디오 오버뷰, 슬라이드, 동영상 개요, 마인드맵, 보고서, 플래시카드, 퀴즈, 인포그래픽, 데이터 표
• 원클릭 삽입 — 열려 있는 맞춤설정란을 자동 감지하고 산출물 유형까지 자동 선택
• 연결 상태 표시 — 삽입 가능 여부를 패널에서 항상 확인
• 노트북 인식 — 현재 노트북 이름을 표시하고, 노트북마다 마지막 입력을 따로 기억
• API 키 없이 AI 다듬기 — Chrome 내장 AI 지원 기기에서는 기기 안에서 프롬프트를 다듬음 (키를 등록하면 클라우드 Gemini 사용 가능)
• 디자인 스타일 9종 — 슬라이드·인포그래픽에 미니멀, 스위스 그리드, 매거진 등 전문 디자인 지시문 적용
• 프리셋·히스토리·내보내기 — 자주 쓰는 설정 저장, JSON으로 공유
• 7개 언어 UI + 결과물 언어 지정

✦ 프라이버시
수집하는 데이터 없음. 서버 없음. 분석 코드 없음. 모든 처리가 브라우저 안에서 이루어지며, 코드는 GitHub에 공개되어 있습니다.

## English (en)

**Short description:**
Better Audio Overviews, slides & quizzes from NotebookLM — build a tailored customization prompt, insert it in one click.

**Detailed description:**

Ever opened NotebookLM's customization box and stared at the blank field, unsure what to write?

Studio Customizer builds an expert-level customization prompt live as you pick an output type and describe your audience and purpose — then inserts it into NotebookLM in one click.

✦ Features
• 9 output types — Audio Overview, Slides, Video Overview, Mind Map, Report, Flashcards, Quiz, Infographic, Data Table
• One-click Insert — detects the open customization box and even auto-selects the matching output type
• Live connection status — always know whether Insert is ready
• Notebook-aware — shows the current notebook's name and remembers your inputs per notebook
• AI refine without an API key — on devices with Chrome's built-in AI, refining runs entirely on-device (add your own Gemini key to use cloud AI instead)
• 9 design styles — apply refined minimal, Swiss grid, editorial magazine and more to slides & infographics
• Presets, history, export/import — save frequent setups, share them as JSON
• Fully multilingual — 7 UI languages, 7 output languages

✦ Privacy
No data collected. No server. No analytics. Everything runs in your browser — and the code is public on GitHub.
